    Quick Reference

    Kruskal's algorithm builds an MST by repeatedly taking the cheapest remaining edge that does not form a cycle.

    Greedy strategy: always take the locally cheapest safe edge. For MSTs this is provably globally optimal (cut property).

    Minimum spanning tree: V-1 edges that connect all V vertices with minimum total weight and no cycles.

    Disjoint Set Union: Find(x) returns a set's root; if Find(u) = Find(v), edge u-v would create a cycle. Union merges two sets.

    Complexity: sorting costs O(E log E). DSU loop costs O(E · α(V)) ≈ constant. Total: O(E log E).
